mend is a command-line tool that applies AI-written edits in four formats — unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON tool calls — to a tree of files, atomically: every file changes or none does. It matches lines at three tiers so wrong line numbers and drifted whitespace or indentation still apply, and it reports exactly what changed, per the specification in SPEC.md.

## Run it

```sh
node main.ts [options] [PATCH]
```
